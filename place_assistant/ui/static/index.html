Place Assistant

Ask about places, products and menus

The assistant picks the right tool for each question: Google Maps, Google Search, the product survey or the area collector. Answers come from those sources, never from memory.

Product survey

Find out whether a product is sold at an area's restaurants, cafes or bars, and at what price.

Surveys need a Maps Platform API key. Set MAPS_API_KEY in .env and restart the UI.

Outlets & menus

Check a list of named places for a product, or read their menus with prices.

Checks need a Maps Platform API key. Set MAPS_API_KEY in .env and restart the UI.
